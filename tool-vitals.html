D

Profil Risiko Investasi

5 pertanyaan untuk menentukan asumsi return realistis. Konservatif → return ekspektasi rendah. Agresif → return tinggi tapi volatilitas tinggi.

1. Horizon investasi utama kamu (sampai uang itu dibutuhkan)?

2. Portofolio kamu turun 30% dalam 1 bulan. Reaksi?

3. Pengalaman investasi pasar modal kamu?

4. Kestabilan pendapatan utama kamu?

5. Kalau target pensiun tertunda 3-5 tahun karena pasar, ok?
